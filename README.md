# Advanced Equipment

Advanced Equipment is an Arma 3 mod for game version 2.20+ that adds mission-ready interactive equipment: laptops with graphical desktop and terminal interfaces, routers, power devices, flash drives, configurable filesystems, desktop apps, browser intel, mail, chat, media, lights, and Zeus/3DEN tooling.

## Requirements

- Arma 3 2.20+
- CBA_A3
- ACE3

## Core Features

- Interactive laptops with GUI desktop and TUI terminal access.
- Built-in desktop apps for files, terminal, settings, mail, chat, browser, calendar, map, CCTV, music, and system info.
- Terminal commands for filesystem work, networking, SSH, messages, encryption, cracking, USB mounting, and system control.
- Mission-maker APIs for users, files, folders, webpages, browser history, media, emails, locked files, power, network, and interface access.
- Zeus and 3DEN modules for live operations and prebuilt mission setup.
- Power simulation with generators, batteries, solar panels, consumers, fuel, charge, and connection logic.
- Network simulation with routers, DHCP, static IPs, gateway routing, SSH, ping, and router configuration.
- Flash drives with inventory/world conversion, USB interfaces, mounting, and persistent filesystem state.
