[h1]Advanced Equipment Revamped[/h1]

Advanced Equipment Revamped adds interactive mission equipment and computer-driven gameplay systems to Arma 3. It is built around usable in-game laptops, routers, power devices, flash drives, lights, desktop apps, terminal commands, browser intel, Zeus tools, and 3DEN setup support.

The mod is intended for players, Zeus operators, mission makers, and communities that want computers and equipment to matter during a scenario instead of acting as static props.

[h2]Main Features[/h2]

[list][*][b]Interactive laptops[/b] with graphical desktop mode, terminal command-line mode, or both.
[*][b]Desktop GUI apps[/b] for Files, Terminal, Settings, Notepad, Mail, Chat, Browser, Calendar, Map, CCTV, Music, and SysInfo.
[*][b]Terminal TUI commands[/b] for file operations, users, permissions, networking, SSH, messaging, USB mounting, encryption, cracking, shutdown, and standby.
[*][b]Browser and webpage intel[/b] with mission-defined pages, browser history, intranet-style clues, and script/module support.
[*][b]Virtual filesystem[/b] with folders, files, owners, permissions, symlinks, mounts, and shared GUI/TUI access.
[*][b]Mission intel tools[/b] for emails, webpages, browser history, locked files, media, calendar events, CCTV cameras, and readable documents.
[*][b]Networking[/b] with routers, SSIDs, passwords, DHCP, static IPs, gateway routing, ping, SSH, and network messages.
[*][b]Power simulation[/b] with generators, batteries, solar panels, fuel, charge levels, power links, standby, overload behavior, and crashed computers.
[*][b]Flash drives[/b] that can be carried, connected to USB interfaces, mounted, unmounted, and browsed from the desktop or terminal.
[*][b]Zeus and 3DEN tools[/b] for building and changing laptop content, power connections, network links, users, files, and live intel during a mission.
[*][b]Full API[/b] documented with hooks for almost all aspect of the framework to be called, invoked, or modified for custom operations and purposes.
[/list]

[hr]
[h2]Laptop Interfaces[/h2]

Each AE3 laptop can be configured for one of three interface modes:
[list]
[*][b]Terminal only[/b] - pure command-line interaction for SSH, messaging, USB, hacking, and file-management gameplay.
[*][b]Desktop only[/b] - graphical app workflow for browser pages, mail, files, media, maps, CCTV, chat, and readable intel.
[*][b]Both[/b] - players can use the laptop as a complete computer with GUI and CLI access.
[/list]
Mission makers can separately restrict GUI and CLI by side, player UID, or custom scripted conditions.

[hr]
[h2]For Mission Makers[/h2]

AE3 is designed to support scenario authoring. You can create a laptop with users, files, emails, webpages, browser history, media, locked files, custom terminal commands, custom desktop apps, network routes, and power requirements.

Zeus can use AE3 tools during live missions to:
[list]
[*]Turn devices on, off, standby, or crash laptops.
[*]Connect and disconnect network or power links.
[*]Add users, files, directories, browser pages, history entries, emails, media, calendar events, encrypted files, and locked files.
[*]Open a laptop filesystem browser and edit contents live.
[*]Control GUI/TUI access for specific players or groups.
[/list]
Full documentation, examples, API references, and developer notes are maintained in the GitHub repository wiki files.
