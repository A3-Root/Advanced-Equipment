[h1]Advanced Equipment[/h1]

Advanced Equipment adds interactive mission equipment for Arma 3 2.20+: laptops, graphical desktops, terminal command lines, routers, flash drives, power devices, media/intel tools, lights, and Zeus/3DEN setup modules.

[h2]Requirements[/h2]
[list]
[*]Arma 3 2.20+
[*]CBA_A3
[*]ACE3
[/list]

[h2]Features[/h2]
[list]
[*]Interactive laptops with GUI desktop and TUI terminal modes
[*]Desktop apps: Files, Terminal, Settings, Mail, Chat, Browser, Calendar, Map, CCTV, Music, and SysInfo
[*]Terminal commands for files, networking, SSH, messaging, encryption, cracking, USB, and power control
[*]Routers, DHCP, static IPs, gateway routing, ping, SSH, and configurable wireless networks
[*]Generators, batteries, solar panels, powered consumers, fuel levels, battery charge, and power links
[*]Flash drives with USB mounting and inventory/world conversion
[*]Mission-maker APIs for users, files, webpages, browser history, media, emails, locked files, networks, and power
[*]Zeus and 3DEN tools for live operations and editor setup
[/list]
