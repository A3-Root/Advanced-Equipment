# Eden Editor Guide

3DEN supports AE3 object attributes, connection types, and modules.

## Connections

Use editor connection tools where available:

- AE3 power connection: connect a consumer to a power source.
- AE3 network connection: connect a device or router to a router.

## Laptop Attributes

Laptops can expose interface settings, filesystem setup, command setup, users, and related AE3 module targets. The GUI and TUI interfaces are independent access surfaces; configure both when the laptop has both modes.

## Router Attributes

Routers support:

- Network name (SSID)
- Default gateway
- Wireless range
- Network password
- Powered on at start
- External SSH/routing access
- External allowed IPs or regexes

## Intel Modules

The desktop module set can add email, webpage, browser history, media, passworded files, and other intel entries. The 3DEN intel control stores the selected intel type and its fields as one module payload.
