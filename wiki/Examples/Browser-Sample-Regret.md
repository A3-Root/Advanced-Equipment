# Browser Sample Regret

`Regret` is a fictional social feed page. It borrows the shape of a familiar social network without copying a real brand.

## What It Shows

- A top bar with search and notifications.
- A left navigation rail.
- A central feed with posts, reactions, and comments.
- A right column with people, groups, and reminders.
- A Markdown companion file for feed-style notes.
- Split source files for HTML, CSS, and JS.

## File Set

```text
sample_files/regret/index.html
sample_files/regret/styles.css
sample_files/regret/app.js
sample_files/regret/feed.md
```

## Why It Is Useful

Use this pattern when you want the browser to feel social and noisy:

- rumor boards,
- faction updates,
- civilian chatter,
- propaganda feeds,
- or fake public social media activity.

It is a good fit for missions where players learn by reading comments, notices, and timeline entries rather than a single static page.

## Example Pattern

```text
Regret
├─ Compose box
├─ Feed cards
├─ People you may know
└─ Trending / community notes
```
