# Eden Attributes

3DEN attributes are available on AE3 devices and modules. Exact labels are localized in stringtables, but the current feature groups are:

## Laptops

- GUI/TUI interface mode.
- Interface access controls.
- Users and command setup through modules.
- Files and directories through filesystem modules.
- Intel entries through desktop modules.

## Routers

- Network Name (SSID)
- Default Gateway
- WiFi Range
- Network Password
- Powered On At Start
- Allow External SSH
- External Allowed IPs
- Power level for internal battery behavior

## Power Devices

- Initial fuel or battery level where supported.
- Powered-on-at-start behavior where supported.

## Editor Connections

- AE3 power connection: consumer to generator, battery, or solar provider.
- AE3 network connection: laptop/router to router.
