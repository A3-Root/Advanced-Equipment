# Zeus Guide

Zeus can place AE3 equipment, connect devices, and inject live intel during a mission.

## Common Zeus Tasks

- Turn devices on, off, or standby.
- Open or close equipment.
- Connect laptops to routers.
- Connect devices to power providers.
- Add users, files, directories, calendar events, webpages, browser history, email, media, and locked files.
- Open a filesystem browser for a laptop and edit its contents live.
- Set GUI/TUI interface access.
- Crash a laptop for scenario effects.

## Live Operation Pattern

1. Place or select a laptop.
2. Add or update user credentials.
3. Add files or webpages that reveal the next objective.
4. If the laptop is networked, connect it to a router or expose SSH.
5. Use interface access controls to decide whether players see GUI, TUI, or both.

See [Zeus Live Operations](Examples/Zeus-Live-Operations.md) for script and module examples.
