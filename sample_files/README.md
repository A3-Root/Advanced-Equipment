# Sample Files

This folder contains source examples for the browser pages documented in `wiki/Examples/`.

The pages are written so they can be opened directly as files in the browser app after you copy them into mission or mod content. Each sample is intentionally split across multiple file types so you can see how a larger page can be organized:

- `index.html` files hold the page shell and working example layout.
- `styles.css` files hold the page styling as a separate source artifact.
- `app.js` files hold the interactive behavior.
- `*.md` files show the markdown rendering path.
- `assets/*.svg` files provide reusable image source art for the gallery example.

The HTML pages are self-contained so they remain usable in the browser app. The separate CSS and JS files mirror the same source so you can split the page apart or reuse just the pieces you need.
